Java-MySQL Database App - portfolio website
===========================================

HOW TO RUN
  Double-click index.html (no server or install needed).

FILES
  index.html       page structure
  css/style.css    all styling
  js/script.js     live CRUD demo + Java code tabs

ADD YOUR LINKS
  Open js/script.js and edit the CONFIG block at the top:
    repoUrl: "https://github.com/your-name/your-repo"
    demoUrl: "https://your-live-demo-url"   (leave empty to scroll to the demo on this page)

NOTE
  The demo on the page runs in the browser and saves to localStorage.
  It shows the SQL your Java app sends to MySQL; it does not connect to a real database.
